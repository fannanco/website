# VibeX Beta Website

واجهة عربية RTL لصفحة تنزيل النسخة التجريبية من VibeX.

## الموجود حالياً
- صفحة هبوط قريبة من التصور المرسل.
- معلومات إصدار Beta.
- زر تنزيل وحالة تقدم مرئية.
- شرح خطوات Android.
- قسم مميزات.
- معاينة مركز الملاحظات.
- نموذج Feedback تجريبي.

## الخطوات التالية
1. استبدال العناصر التوضيحية بصور VibeX الأصلية.
2. ربط زر التنزيل بملف APK حقيقي أو رابط إصدار.
3. إضافة API لإرسال الملاحظات والصور.
4. إضافة معلومات الجهاز والإصدار تلقائياً داخل التطبيق.
5. إعداد نطاق beta.vibex.app وCI/CD.

> تنبيه: شريط التقدم الحالي تجريبي للواجهة فقط ولا يمثل تنزيل APK حقيقي.
