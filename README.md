# VibeX Beta Website

واجهة عربية RTL لصفحة تنزيل النسخة التجريبية من VibeX، مبنية لتكون جاهزة للربط الحقيقي بملف APK وخدمة استقبال الملاحظات.

## الموجود
- صفحة هبوط مطابقة لاتجاه التصميم المطلوب.
- معلومات الإصدار والحجم والتحديث.
- زر تنزيل Android.
- حالة تنزيل وتعليمات تثبيت Android.
- قائمة تنقل بسيطة.
- قسم مميزات.
- مركز ملاحظات مع نوع المشكلة والوصف ورفع صورة.
- جمع معلومات المتصفح/النظام تلقائيًا للبلاغ.
- ملف config.js لتفعيل الروابط الحقيقية بدون تعديل الكود الرئيسي.

## تفعيل ملف APK
افتح `config.js` وضع رابط ملف APK في:
```js
apkUrl: "https://example.com/VibeX-v0.9.0.apk"
```

## تفعيل إرسال الملاحظات
ضع عنوان API يقبل POST multipart/form-data في:
```js
feedbackEndpoint: "https://api.example.com/v1/beta-feedback"
```

الحقول المرسلة:
- type
- description
- userAgent
- platform
- appVersion
- image (اختياري)

## المطلوب خارجيًا قبل الإطلاق العام
- ملف APK حقيقي أو رابط تنزيل مباشر.
- API حقيقي لاستقبال البلاغات.
- استضافة وربط النطاق beta.vibex.app.
- صور/لقطات VibeX الأصلية إذا أردنا مطابقة الصورة المرجعية 1:1.
